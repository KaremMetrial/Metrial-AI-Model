# Answer key — DO NOT OPEN until every run is finished and scored

`A_truth.json` lists the planted causes and their effects for dataset A. `C_truth.json` states that dataset C has no planted cause and gives the normal monthly variation.
Effects in `A_truth.json` are measured against a counterfactual in which the planted event is removed while all other random draws are identical (basis points of October gross margin). A bridge between September and October will not match them exactly because September-to-October also includes ordinary seasonality and interactions; the pre-registration therefore allows ±35% or a stated method whose components sum to the observed change.
